# Santiment Plans

Santiment offers tiered subscription plans for both Sanbase (the analytics
platform) and SanAPI (the GraphQL data API). All plans share the same API
endpoint; the plan level controls rate limits, historical data depth, and
access to restricted metrics.

## Individual Plans

### Free
- **Cost**: $0 / month
- **Monthly API calls**: 1,000
- **Hourly API calls**: 500
- **Per-minute API calls**: 100
- **Historical data (API)**: 1 year (last 30 days of restricted metrics excluded)
- **Notes**: Limited screener, up to 3 alerts, hidden top 3 trending tokens

### Sanbase Pro
- **Cost**: $49 / month ($529 / year — ~10 % discount)
- **Monthly API calls**: 5,000
- **Hourly API calls**: 1,000
- **Per-minute API calls**: 100
- **Historical data (API)**: 1 year (last 30 days of restricted metrics excluded)
- **Notes**: Real-time data, 20 active alerts, Google Sheets plugin, exclusive reports
- **SAN token discount**: 20 % off when holding SAN tokens

### Sanbase Max
- **Cost**: $249 / month ($2,700 / year — ~10 % discount)
- **Monthly API calls**: 80,000
- **Hourly API calls**: 4,000
- **Per-minute API calls**: 100
- **Historical data (API)**: 2 years, no real-time restriction
- **Notes**: 50 active alerts, technical support, full metric access
- **SAN token discount**: 20 % off when holding SAN tokens

## Business Plans

### Business Pro
- **Monthly API calls**: 600,000
- **Hourly API calls**: 30,000
- **Per-minute API calls**: 600
- **Historical data (API)**: 2 years, no real-time restriction
- **Notes**: Suitable for quant pipelines and institutional data consumers

### Business Max
- **Monthly API calls**: 1,200,000
- **Hourly API calls**: 60,000
- **Per-minute API calls**: 1,200
- **Historical data (API)**: Full access to all metrics
- **Notes**: Highest self-serve tier; ideal for production data products

### Enterprise
- **Rate limits**: Custom
- **Historical data (API)**: Full, unrestricted
- **Notes**: Custom pricing and SLAs; contact Santiment sales for a quote

## Payment Options

- **Fiat**: Credit card (monthly billing)
- **Crypto (annual plans)**: ETH, DAI, USDC, USDT
- **SAN token burn**: Credited at 2× market value when paying with SAN
